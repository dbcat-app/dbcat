# DbCat

快速、原生的 macOS 数据库客户端，支持 MySQL / MariaDB、PostgreSQL、SQLite。

A fast, native macOS database client for MySQL / MariaDB, PostgreSQL and SQLite.

- **下载 / Download**：[Releases](https://github.com/dbcat-app/dbcat/releases)（需要 Apple Silicon、macOS 12 及以上 / requires Apple Silicon, macOS 12+）
- **反馈问题 / Report an issue**：[Issues](https://github.com/dbcat-app/dbcat/issues)（应用内"帮助 → 报告问题…" / Help → Report Issue… in the app）
- 应用内置自动更新 / Built-in automatic updates

本仓库只用于发布版本与问题反馈，不包含源代码。
This repository hosts releases and the issue tracker only; it does not contain source code.
